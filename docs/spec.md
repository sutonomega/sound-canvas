# Sound Canvas：v1.0機能仕様

対応Issue: [#2](https://github.com/sutonomega/sound-canvas/issues/2)。本書は目標仕様であり、0.1の実装済み挙動とは区別する。[公開範囲](service-scope.md)を前提とする。

## 基本の操作

1. MP3/WAVを選択またはドロップする。自動再生せず、全曲解析の完了後に再生可能にする。
2. 再生・一時停止・シークで曲を確認する。停止中の画面はその位置の作品を保持する。
3. スタイル、テーマ、反応、軌跡、比率を変更する。現在位置まで新しい設定で描き直す。
4. 現在のPNG、完成アートPNG、音声付きWebMから目的の保存を選ぶ。

デモ音源でも同じ操作経路を使う。音源ファイルの拡張子だけで成功扱いにせず、デコード失敗を読み込みエラーとして扱う。音源は端末内だけで処理し、解析値や音声を外部へ送信しない。

## 状態と競合操作

| 状態 | 表示と操作 |
| --- | --- |
| 未読込 | 読込・デモ・設定を利用可能。再生・シーク・保存は無効。初期イメージは実際の楽曲結果と区別する |
| 読込/解析中 | 処理中表示と進捗、判定可能なら容量・長さを示す。再生・保存は無効。中止または再選択で古い処理結果を破棄できる |
| 準備/一時停止 | 現在時刻の描画を保持。再生・シーク・設定・保存を利用可能 |
| 再生中 | 音声の再生時刻に描画を追従。設定変更・シーク時は一時的に音声を止め、復元後に再生を再開する |
| 復元中 | 対象時刻と処理中表示。再生・PNG/動画開始は無効。新しいシーク・設定・読込は古い復元を中止し、最後の要求だけを反映する |
| 終端 | 終端の完成画面を保持。再生で0秒から描画も初期化して再開する |
| 録画準備/録画中 | 曲と設定を固定する。読込・シーク・設定変更・通常再生・PNG操作を無効にし、進捗と中止だけを提供する |
| PNG生成中 | 保存対象時刻まで復元する。中断・失敗から復帰可能とし、処理途中の画像を保存しない |

エラーは独立した行き止まりにしない。音源差替えは成功時に確定し、失敗・中止時は前の楽曲と設定へ戻れるようにする。古い解析や復元が新しい曲を上書きしない。生成前の位置と再生中/停止中の状態を保持し、録画・完成PNGの完了/中止後はその位置へ復元して一時停止する（勝手に音を再開しない）。

「最初に戻る」は0秒に移動して一時停止し、蓄積を消す。「一時停止」は蓄積を消さない。設定は曲の全区間に適用され、変更前の軌跡を混在させない。

## 音楽解析

全曲を事前解析し、30Hzの特徴フレームを保持する。最終区間は曲末までの実サンプルを対象とする。各値は有限で0〜1、無音は0とし、曲単位の正規化と無音時の除算保護を行う。

| 値 | 意味 | 主な描画への反映 |
| --- | --- | --- |
| volume | 全帯域の強さ | 線幅・明るさ |
| bass | 低音の強さ | 広がり・半径・波紋 |
| mid | 中音の強さ | 曲線・移動速度 |
| high | 高音の強さ | 細粒子・細部 |
| beat | 瞬間的な立ち上がりの推定 | 発光等の一度の演出 |
| intensity | 中長期の強さ・密度の簡易推定 | 粒子数・動きの勢い |

### 解析方式 `sc-analysis-3`（Issue #6・#13）

- チャンネルごとに2次フィルター（Q=1/√2）を適用する。低音は200Hzローパス、中音は200Hzハイパス→2400Hzローパス、高音は2400Hzハイパスとする。境界は緩やかで重なりがあり、3帯域の和が全体音量に一致することは要求しない。極端に低いサンプルレートではカットオフをレートの45%以下へ制限する。
- 波形を先に混ぜず、各チャンネルの二乗和を統合してRMSを算出する。左右逆相でも相殺されない。
- 全曲の生のvolume最大値を共通の正規化基準とし、下限を0.0001にする。帯域を個別に最大化しない。RMSが0.0000001未満は数値ノイズとして0とする。各出力は0〜1に制限する。
- 連続値volume/bass/mid/highは、立上り0.06秒・減衰0.25秒の指数平滑化を適用する。係数は区間のdtから算出し、曲末の端数区間も扱う。全曲無音は厳密に0とし、音の直後の無音には平滑化の減衰が残る。
- beatは平滑化前の低音の立上りを使う。volume>0.06、bass>max(0.06, 過去平均×1.5)、前フレームからのbass増分>0.04を満たし、前イベントから6フレーム（200ms）以上経過したときに発火する。過去平均は0.5秒の指数平均で、判定後に更新する。正確なBPMや拍子・サビの検出は目的にしない。
- intensityは `0.7×volume + 0.2×帯域活動量 + 0.1×ビート密度` を、立上り1秒・減衰2.5秒で平滑化する。活動量は平滑化後のbass+mid+highを0〜1に制限した値。ビート密度はbeatの1.5秒指数平均×15を0〜1に制限した値。曲の展開に対する簡易推定である。

平滑化は事前解析で一度行い、再生時のフレームレートに依存させない。同じ全曲解析データを再生・シーク・各スタイルから再利用する。解析方式・係数を変更するときは版を更新する。実測と確認範囲は[Issue #6の確認記録](issue-6-validation.md)を参照する。有機的な曲線ではIssue #8でintensityの利用を実装する。他のスタイルはそれぞれの描画Issueで実装する。

## 描画と設定

初期値は有機的な曲線、Aurora、反応100%、蓄積、9:16。テーマはAurora/Ember/Oceanの3種以上、反応は25〜200%。無音で音由来の新しい強い発光や粒子を発生させない。

- 有機的な曲線：滑らかな曲線を蓄積し、中音の変化を動きへ反映する。
- 幾何学：円運動と三角関数を基に、低音で半径、ビートで回転・発光を変える。
- 粒子：高音で細粒子、低音で拡散、intensityで密度・勢いを変え、寿命と数の上限を設ける。
- 簡易水彩：半透明・ぼかし・ノイズで色の広がりを表現し、低音で塊、高音で細部を作る。本格流体計算は要求しない。

### 有機的な曲線 `organic-2`（Issue #8）

7本の曲線が、固定シードの初期位相と音楽に応じた移動時計で動く。volumeを線幅・輝度、bassを広がり、midを曲線の進行速度と追従、highを小さなきらめき、beatを短寿命の発光、intensityを移動速度・細部の密度・発光数に反映する。

静かな区間でも線が見えるよう、輝度の変化に平方根の応答を用いる。反応設定は各値に適用し、過剰な幅・発光にならないよう上限を設ける。無音では新しい線・きらめき・ビート発光を描かない。既存の発光は寿命で消えるが、曲末に到達した時点では仕様どおり完成した画面を固定する。

色を加算し続ける方式ではなく、source-overで色を重ねて描き、長時間の交差部分が白くなり続けるのを抑える。描画領域には短辺に応じた余白を設け、線・制御点・発光を3比率の内側に収める。減衰モードでは共通エンジンが軌跡を徐々に透明へ戻す。

移動時計・きらめきの発生余り・乱数状態も復元対象とする。スタイル版の変更によりorganic-1と同じ曲でも形は変わるが、organic-2の同じ入力・設定・時刻では再現する。[比較画像と確認記録](issue-8-validation.md)を参照する。

### 幾何学模様 `geometric-1`（Issue #9）

固定シードで選んだ組合せの3本の内トロコイドを描き、スピログラフ風の模様を蓄積する。低音は半径、中音・盛り上がりは描画速度、高音は細部の形、音量は線幅・明るさを変える。ビートは短時間の回転加速と一時的な発光・円に反映し、角度を瞬間的に飛ばさない。

短辺に合わせて円の半径を決め、全テーマ・3比率・蓄積/減衰に対応する。無音では新しい線・ビート演出を作らず、既存の演出だけが寿命で消える。曲末はその位置の合成画面を保持する。

設定欄に有機的な曲線・幾何学模様・粒子アート・流体/水彩の選択ボタンを表示する。一度に選べるのは1種類。初期値は有機的な曲線のまま。再生中の変更は一時停止して現在位置まで再計算し、完了後に再開する。読込/解析中はスタイル変更を無効にし、復元中は最後の選択を優先する。[比較画像と確認記録](issue-9-validation.md)を参照する。

背景、蓄積される描画、動き続ける演出の3層を合成する。蓄積は曲の進行で成長、減衰は固定刻みに基づき徐々に消える。曲末で時間更新を止め、その時点の合成画面を完成アートとする。終端だけ別のフィルターをかけない。

| 比率 | 初期出力解像度 |
| --- | --- |
| 9:16 | 720 × 1280 |
| 16:9 | 1280 × 720 |
| 1:1 | 1080 × 1080 |

プレビュー表示はこの同一キャンバスを縮小し、縦横比を保つ。操作UI・ラベル・ローディング表示は出力画像に含めない。追加の解像度選択はv1.0必須ではない。

## 時間と再現性

同じ音源の解析結果、シード、設定、描画エンジンの版、出力解像度が同じなら、同じブラウザ環境内で同じ時刻の結果を再現する。ファイル名はシードに含めない。時刻は描画済みステップ数へ変換し、処理落ち時も必要なステップを飛ばさない。

シークは0秒からの再計算または有効なスナップショットからの再計算で復元する。画素だけでなく粒子・乱数等の内部状態も対象。設定変更で過去キャッシュを混ぜない。別ブラウザ間の画素完全一致、異なるデコード結果間の一致は保証外である。

## PNGとWebM

現在のPNGは指定位置への描画が完了した合成画面を保存する。完成PNGは曲末まで生成して保存する。どちらも表の解像度で出力し、生成失敗時は保存成功と表示しない。

WebMは冒頭からの全曲録画を基本とする。実行時に必要なAPIとMIMEの対応を判定し、音声と映像の両トラックを含める。録画前に位置・設定を固定し、録画開始を準備してから音声を開始する。終端の描画まで完了して停止し、最終データを受け取ってからダウンロード可能にする。音が無い曲でも音声トラックを保つ。

中止した録画は完成MVとして保存せず破棄する。失敗・中止・正常終了のすべてで録画専用ノード、ストリーム、タイマー、保存用URL等を解放し、次の制作を可能にする。タブ非表示や処理遅延で同期を維持できない場合は中止して理由を示す。バックグラウンド録画を保証しない。

## 受入確認

- 既知周波数、無音、左右逆相、強弱変化で解析の有限値・帯域反応・ビートの過剰連打防止を確認する。
- 短曲、3〜5分、長曲、大容量、破損入力、連続差替えを確認し、上限や失敗表示を記録する。長曲の具体的な試験長・許容量は#18で実測して公開前に確定する。
- 全4スタイル・3比率・両軌跡で、0秒/中間/終端、再生/シーク/連続設定変更の結果を確認する。再現性は同一環境の画素または内部状態で比較し、単なる目視一致だけで合格にしない。
- WebMの音声/映像トラック、解像度、冒頭/中間/終端の同期、最終画面、正常終了/中止/非対応/非表示時の挙動を確認する。同期の暫定目標は基準音と対応演出の差100ms以内とし、#16で測定方法・実測値と達否を記録する。値を変更する場合は根拠を本書とIssueに残す。
- PNGが指定画素数で開け、現在位置と曲末の画像を取り違えないことを確認する。
- Chrome/Edge/Firefox/Safariの実際に試した版と対応範囲を#18で記録する。録画非対応は説明付きで扱い、全ブラウザで録画できると事前に約束しない。
- キーボードで読込から保存まで操作でき、進捗・エラーを色だけに頼らず伝えられる。個人の実音源は公開せず、合成音源や権利確認済み素材で再現条件を残す。

## 粒子アートの実装（Issue #10）

`particles-1` は高音で細かい粒子、低音で拡散、中音で旋回、盛り上がりで密度と速度、ビートで追加発生、音量で太さと明るさを変える。粒子の移動線を描画層へ蓄積し、光点と発光は演出層へ描く。無音では新規発生せず、既存粒子は寿命まで動く。粒子は最大256個、寿命1.2〜3秒、発光は1ステップ最大32個。全テーマ・3比率・蓄積/減衰と現在PNGを共用する。[確認記録](issue-10-validation.md)。

## 簡易水彩の実装（Issue #11）

`watercolor-1` は半透明の色のにじみと決定的な輪郭変形で水彩風に描く。低音は塊の大きさと広がり、中音は移動、高音は細かな顔料、intensityは速度と密度、音量は濃さに反映する。ビートでは短寿命のにじみを最大18個まで作り、演出層へ描く。無音では新しい塗りとビート演出を発生させない。全テーマ・3比率・両軌跡・現在PNGを共用する。本格的な流体計算・顔料の物理混色は行わない。[比較と確認記録](issue-11-validation.md)。

Issue #11では共通描画エンジンを `sc-renderer-3` に更新した。減衰時の薄い灰色の消え残りを抑えるため、4ステップ（約0.133秒）分の透明化をまとめて適用する。基準の1/30秒あたり0.018は維持する。曲末では未処理分と端数時間を適用して完成状態を固定する。全スタイルの減衰結果が従来版から変わるため、版の異なる保存状態は混ぜない。8ビットCanvasでの完全な透明への収束は保証しない。

## 設定の統合（Issue #12）

4スタイルの単独選択、3テーマ、反応25〜200%、蓄積/減衰、3比率を同じ設定パネルから操作する。テーマの色見本は定義済みの色相を彩度85%・明度60%で表示する。映像の明るさは音量やスタイルでも変化する。

選択表示、テーマ、反応の確定値、軌跡、出力サイズは描画エンジンの設定から同期する。反応スライダーの操作中は入力値を保ち、確定時に再計算する。入力を取り消した場合は適用済みの値へ戻す。同じ設定・比率の選び直しでは再計算や再生中断を行わない。

未読込でも設定でき、読み込み中は4スタイルと全設定を無効にする。復元中は設定変更を許可し、最後の変更だけを反映する。保存は現在位置の描画が完了するまで無効。設定適用に失敗した場合は従来の描画を保持し、操作欄も適用済みの値へ同期する。[全組合せと確認記録](issue-12-validation.md)。動画・完成PNGの生成中の排他制御は、その機能を追加する#15/#17で接続する。

## 再現性の時刻境界と許容条件（Issue #13）

1/30秒の境界付近では、`ticks = time * 30` と最寄り整数との差が `max(1e-8, 4 * Number.EPSILON * max(1, abs(ticks)))` 以下なら整数へ補正してからfloor/ceilする。固定下限1e-8コマは約0.33ナノ秒で、音声時計の加減算や整数境界の浮動小数点誤差を吸収する。境界以外の端数は維持する。48kHzで最後に1サンプル余る区間も省略しない。解析フレーム数と描画済み数を同じ関数で決め、端数dtも共通関数から取得する。

解析版はsc-analysis-3、描画版はsc-renderer-4。境界や曲末で以前の版とフレーム数が変わるため、以前の保存状態は利用しない。音声時刻はoffsetに開始後の経過時間を加えて求め、加減算の桁落ちを抑える。

同一環境・同一PCM解析結果・シード・設定・時刻・解像度・版での検証は、合成画面と内部3層のRGBA差0、スタイル状態・乱数の差0を合格条件とする。上記の時刻境界補正は画素差の許容ではない。ブラウザ・OS・デコード・Canvasの実装や版が異なる環境間の画素完全一致は保証しない。MP3/WAVの再デコードでPCMが変われば別の解析結果として扱う。[条件と実測](issue-13-validation.md)を参照する。

## シークの再利用と操作（Issue #14）

同じ曲・解析版・描画版・スタイル版・シード・設定・出力サイズで、移動先以前の現在の描画状態と保存状態を比較し、より進んだ位置から再計算する。通常再生・復元時に15秒ごと、復元完了時にも状態を保存する。保存状態は最大4件、3層CanvasのRGBAバイト数と状態JSONのUTF-16長の合計見積りが48MiB以内になるよう保持し、古く使われていないものから解放する。背景も含む保存面は独立したコピーである。

曲の読み込み成功時と設定・比率等のキーが変わると保存状態を無効にし、Canvasを解放する。保存面の作成に失敗しても再計算を継続する。不正な保存状態は破棄し、冒頭から作り直す。保存が無い場所への移動や初回は全区間の再計算が必要な場合がある。

復元は8msを目安・最大120ステップの単位で処理を分け、移動先と進捗を表示する。1ステップの描画や保存面のコピーは分割できないため、8msを厳密な停止時間上限とはしない。復元中も別のシーク・設定変更・曲選択を受け付け、最後の要求だけを有効にする。PNGと通常再生は完了まで無効。「中止して最初に戻る」は現在の設定を保持し、0秒の停止画面へ戻す。

48MiBは保存する描画状態の保持量の見積りであり、音声・現在の描画面・復元用の一時コピー・ブラウザやGPUの内部領域は含まない。実測条件・初回の追加負荷・制限は[性能確認記録](issue-14-validation.md)を参照する。

## 音声付きWebMの実装（Issue #15）

現在位置にかかわらず、設定を固定して冒頭から全曲を実時間録画する。Canvas captureStream・MediaStream・MediaRecorder・Web Audioの録画用音声出力とWebM対応形式を確認する。形式はVP8+Opus、VP9+Opus、汎用WebMの順で確認する。対応しなければ理由とPNG等の案内を表示する。録画のためにマイクは使用しない。

「音声付きMVを録画する」で通常音声を止め、専用の音源をスピーカーと録画用音声出力へ接続する。MediaRecorder.start後に最初のCanvasフレームを要求し、音声を現在の音声時計+0.1秒に予約する。録画開始イベントだけを待って音声を止めたままにしない。音声時計を基準に共通Rendererを進め、合成済みフレームを要求する。終端は最後の端数ステップを描き、追加の画面更新を2回待ってから録画を終了する。時間精度はブラウザ依存であり、100msの同期目標の達否は#16で測定する。

準備・録画・終了処理と復元が終わるまで、曲選択・設定・再生・先頭戻し・シーク・PNGを無効にする。録画中は進捗と中止を提供する。終了処理中の中止ボタンは無効にする。完了・失敗・中止後は開始前の位置に復元して停止する。完了時は「直前のMVを保存（WebM）」から保存し、録画した曲名も表示する。再録画や曲の読み替えでは以前の保存URLを解放する。

非表示、音声時計の停止、トラック停止、MediaRecorderエラー、描画遅延が6ステップを超えた場合、途中動画を破棄して理由を表示する。遅延の200ms相当の閾値は録画中止のための暫定値で、同期精度の保証ではない。録画開始を10秒、終了を5秒待っても完了しなければ失敗として復旧する。記録済みチャンクが256MiBを超えた場合も中止する。画質の目安は映像5Mbps・音声160kbpsで、実際のビットレートはブラウザに依存する。

音声源・接続・録画トラック・イベント・タイマー・途中Blobを終了時に解放し、共有AudioContextは通常制作のために保持する。成功BlobとURLは保存用に保持し、次の録画・曲の読み替え・画面終了で解放する。[検証範囲とサンプル](issue-15-validation.md)を参照する。
