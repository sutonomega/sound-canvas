# Sound Canvas 利用ガイド

このガイドは **devのv1.0公開候補** の画面を対象にしています。2026-11-13時点の[公開アプリ](https://sutonomega.github.io/sound-canvas/)はmainの0.1版で、操作・保存機能が異なります。公開前の版は[ローカル起動手順](development-and-release.md)で利用できます。

## 最初の一曲

1. PCブラウザで開き、「楽曲をドロップ / 選択」からMP3またはWAVを選ぶか、ファイルを画面へドロップします。「デモを体験する」なら音源なしでも試せます。
2. 曲全体の解析が終わったら、プレビュー下の ▶ を押します。音量や帯域に合わせて光が動き、軌跡が残ります。スピーカーの音量にも注意してください。
3. Ⅱ で一時停止、↺ で最初に戻ります。再生位置のつまみで途中へ移動できます。移動先の軌跡を復元する間は進捗を表示します。
4. 右側で好みのスタイルや色を選びます。変更すると、その設定で現在位置まで描き直します。
5. 画像ならPNG生成、音声付き動画ならMV録画を選び、準備完了後に表示される保存リンクを押します。

自動保存はありません。再読み込みやタブを閉じる前に、必要なPNG・WebMを保存してください。読み込んだ曲、設定、未保存の成果物は次回へ引き継ぎません。

## 表現を変える

| 設定 | 選べる内容・効果 |
| --- | --- |
| 映像スタイル | 有機的な曲線／幾何学模様／粒子アート／流体・水彩。初期版は一度に1種類です。水彩は半透明描画などによる簡易表現です。 |
| カラーテーマ | オーロラ／残り火／深海。色見本も切り替わります。 |
| 反応の強さ | 25〜200%。まず100%で試し、動きが強すぎる場合は下げます。 |
| 軌跡 | 「積み重ねる」は絵を蓄積。「ゆっくり消える」は過去の線が徐々に消えます。 |
| 画面比率 | 初期値9:16（720×1280）、16:9（1280×720）、1:1（1080×1080）。PNGとMVもこの寸法です。 |

同じ曲・設定・時刻では同じ絵を再現する設計です。ただし、アプリの描画方式の更新やブラウザの音声処理・Canvasの違いをまたぐ完全一致は保証しません。作り直す予定なら、元音源と設定、アプリの版も手元に記録してください。

## PNGを保存する

- 「現在のアートをPNGにする」：現在の再生位置の絵を生成します。
- 「曲末の完成アートをPNGにする」：曲末まで描いた絵を生成します。曲を最後まで再生しておく必要はありません。

生成開始時に一時停止し、元のプレビューと再生位置を保ったまま別の描画面で計算します。背景・描画・演出を含むPNGです。「ゆっくり消える」の完成アートも曲末時点の絵で、消えた軌跡を戻す機能ではありません。

生成中は設定や再生などを操作できません。「PNG生成を中止」で中止できます。完了したら「現在のアートを保存（PNG）」または「曲末の完成アートを保存（PNG）」を押し、ブラウザの保存先でファイルを確認してください。中止・失敗時は途中画像を保存せず、元の位置で停止します。

## 音声付きMVを保存する

1. 音源と設定を決め、「音声付きMVを録画する」を押します。現在位置にかかわらず、曲頭から全曲を録画します。
2. 曲の長さと同程度の時間、画面を表示したまま待ちます。他タブへの移動、最小化、スリープ、重い作業を避けてください。
3. 完了後、元の再生位置へ戻って停止します。「直前のMVを保存（WebM）」を押し、保存した動画の音と映像を確認します。

録画中の操作は制限され、「録画を中止」で中止できます。非表示や大きな描画遅延などを検出した場合も中止し、途中動画を保存しません。終了処理・位置の復元中は待ってください。録画データは256MiBを超えると中止します。長い曲や複雑な表現では短い曲から試してください。

出力は対応ブラウザでの **WebM** です。MP4変換、途中区間だけの書き出し、投稿サービスへの直接送信はありません。投稿先が受け付ける形式や容量は投稿時に確認してください。詳しくは[録画ガイド](recording-guide.md)を参照してください。

## キーボードで操作する

Tab／Shift+Tabで移動し、ボタンはEnterまたはSpaceで実行します。曲選択はSpaceでファイル選択を開けます。再生位置にフォーカスがあるときは、矢印で1秒、Shift+矢印またはPage Up／Page Downで10秒、Home／Endで曲頭／曲末へ移動します。全画面共通のSpace再生ショートカットはありません。

復元中に別の位置や設定を選ぶと、最後の指定を反映します。「中止して最初に戻る」は復元を止め、曲頭へ戻ります。保存できない間は保存欄の案内を確認してください。[操作性の検証範囲](issue-19-validation.md)には、支援技術などの未確認事項も記録しています。

## 困ったとき

| 状況 | 対応 |
| --- | --- |
| 読み込めない | MP3／WAVか、別の音楽プレーヤーで再生できるかを確認。別の短い曲やデモでも試します。失敗しても直前の読み込み済み曲は保持します。 |
| 読み込みが長い | 曲全体を解析するため待ち時間があります。「読み込みを中止」や別のファイルの選択ができます。大きなWAVより短いMP3から試します。 |
| 音が出ない | ▶ を押し、端末・ブラウザ・タブの消音設定を確認します。 |
| シーク・完成PNGが遅い | 初回は曲頭からの計算が必要です。進捗を確認し、必要なら中止します。 |
| 録画が中止された | 表示したまま、他の重い作業を止めて再試行。短い曲・別のスタイルでも確認します。エラーが続く場合は表示文を記録してください。 |
| 保存ファイルがない | 生成・録画完了だけでは保存されません。保存リンクとブラウザのダウンロード一覧・保存先を確認します。 |

試し直すために再読み込みする場合は、先に保存可能な成果物を保存してください。

## 動作範囲と音源の扱い

Windows / Chrome 157・Edge 157で確認していますが、検証内容は同一ではありません。約3分半〜5分の実音源MP3 4曲の全曲MVはChromeの自動操作環境、通常Chrome・Edgeは短い録画などを確認しています。10分WAVは解析・シーク・完成PNGまでで、10分の全曲MVは未確認です。Firefox・Safari・他OS・スマートフォンの全曲録画は未確認です。[環境別の確認記録](release-checklist.md)を参照してください。

音源全体をメモリへ展開し、復元やPNG生成にも追加メモリを使います。約5分のMP3でも展開後の音声だけで100MB程度になる場合があります。長時間・大容量WAVの快適な動作や、すべてのPCでの録画成功は保証しません。

音源の解析と描画は端末のブラウザ内で行い、音源をサーバーへ送信しません。アカウント、マイク、カメラは不要です。アプリの配信や外部フォントの取得には通信があります。保存したMVには元の音声が入ります。

読み込み・公開には利用できる音源や素材を使い、AI音楽サービスも含め、利用元の規約と公開・投稿に必要な権利を確認してください。自作曲であっても、第三者の素材を含む場合はその条件も確認します。

歌詞、曲名・アーティスト名の表示、複数スタイル合成、プリセット保存、MP4、短尺切り抜きは未実装です。[将来拡張 #22](https://github.com/sutonomega/sound-canvas/issues/22)で管理しています。

## 不具合を報告する

[不具合報告Issue](https://github.com/sutonomega/sound-canvas/issues/new?template=bug-report.md)に、利用URL（公開版／ローカル）、版やブランチが分かればその情報、OS・ブラウザとバージョン、操作手順、期待した結果と実際の結果を記入してください。設定5項目、曲の形式・長さ・おおよその容量、発生位置、デモでも起こるか、画面のエラー表示があると調査しやすくなります。

音源添付は必須ではありません。曲名・ローカルパス・個人情報・権利上公開できない音声やMVを公開Issueへ載せないでください。画像やログも送信前に内容を確認してください。
