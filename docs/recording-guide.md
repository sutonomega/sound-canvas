# 音声付きMVを保存する

1. MP3/WAVを読み込み、解析が終わったらスタイル・色・反応・軌跡・比率を選びます。
2. 「音声付きMVを録画する」を押します。現在の位置にかかわらず、冒頭から全曲を録画します。
3. 曲と同程度の時間、この画面を表示したまま待ちます。録画中は設定を変更できません。
4. 完了したら「直前のMVを保存（WebM）」で保存します。終了後は開始前の位置へ戻って停止します。

録画を中止すると途中動画は保存されません。大きな処理遅延や非表示の通知を検出した場合も中止します。他の重い処理を終了し、画面を表示したまま再試行してください。自動操作環境では非表示通知が発生しない場合があるため、通知だけに頼らず録画中は画面を維持してください。

初期版の確認対象はPCのWindows / Chrome 157・Edge 157です。通常Chrome/Edgeで短い合成音のVP8/Opus録画を確認し、Chrome系のアプリ内ブラウザで実音源4曲（約3分半〜5分）の全曲MVも確認しました。Edgeでは実音源の再生・PNGと、実際の別タブ切替による録画中断を確認しました。ブラウザごとの実施範囲は[リリース確認記録](release-checklist.md)を参照してください。Firefox・Safari、他OSは未確認です。

まず3〜5分程度のMP3で試すことを目安とします。9:16は720×1280、16:9は1280×720、1:1は1080×1080です。専用の短い合成音で測った音と映像のずれは最大17msでしたが、すべての端末・曲で100ms以内を保証するものではありません。10分の合成WAVは解析と完成PNGまで確認し、10分の全曲MVは未確認です。

WebMは圧縮するため、細い線・微粒子・色にプレビューとの差が出ます。開始・終了には短い余白が付き、ファイルの長さが曲と完全一致しない場合があります。動画対応形式はブラウザにより異なり、非対応時は画面に理由を表示します。MP4出力は未対応です。記録データが256MiBを超えると中止します。長時間の曲や大容量WAVはメモリ負荷にも注意してください。

楽曲は端末内で処理し、録画にマイクは使いません。投稿先がWebMに対応しない場合は別の変換手段が必要です。測定条件・許容値・未確認事項は[確認記録](issue-16-validation.md)に記載しています。
