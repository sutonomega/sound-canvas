## 今回のCI変更

- dev・main宛PRとdevへのpushで[checks.yml](../.github/workflows/checks.yml)を実行。Node.js 24を明示し、依存パッケージのインストールは不要。
- `npm run check`でdist・tests・scripts以下のJavaScriptを再帰的に構文確認。新しいファイルやPNG・操作性モジュールも列挙漏れなく対象にする。
- `npm test`で解析・再生・復元・描画・出力の自動テストを実行。
- [pages.yml](../.github/workflows/pages.yml)も同じチェックを呼び、成功を公開の前提にする。デプロイはmainだけで実行し、Pages書き込み権限はデプロイジョブへ限定する。

自動チェックは実ブラウザでの音声・Canvas・ダウンロードの確認を代替しない。ブランチ保護で必須チェックを設定したことも意味しない。マージ前にPRのChecksを確認する。[再利用ワークフローの公式仕様](https://docs.github.com/en/actions/how-tos/reuse-automations/reuse-workflows)に従う。

## リリースノート案（原稿履歴）

Sound Canvas v1.0.0は、MP3・WAVから音楽に反応する抽象アートと音声付きMVを作るブラウザアプリです。

- 曲全体の音量・低中高域・簡易ビート・盛り上がりを解析し、曲線・幾何学・粒子・簡易水彩の4スタイルで描画。
- 3テーマ、反応の強さ、蓄積／減衰、9:16・16:9・1:1に対応。
- 再生・停止・シーク、同じ曲と設定に基づく軌跡の復元。
- 現在／曲末のPNGと、音声付き全曲WebMの生成・保存。進捗、中止、失敗後の復帰に対応。
- キーボード操作、保存案内、利用・開発・公開ガイドを整備。

音源は端末のブラウザ内で処理します。公開・投稿できる権利のある素材をご利用ください。アプリ・外部フォントの取得には通信があります。

Windows / Chrome 157・Edge 157を確認対象とし、詳しい実施範囲は[環境別記録](release-checklist.md)をご覧ください。Firefox・Safari・他OS、スマートフォンでの全曲録画、10分の全曲MVは未確認です。すべてのPCでの性能・ブラウザ間の画素一致を保証しません。

MVは実時間録画で、画面を表示したまま待つ必要があります。非表示・大きな遅延などの検出時や256MiB超過時は中止します。長時間・大容量音源ではメモリと性能の制約があります。生成後は保存リンクを押してください。自動保存はありません。

MP4、歌詞・曲名表示、複数スタイル合成、プリセット保存、短尺切り抜きは今後の拡張です。[利用ガイド](user-guide.md)と[将来拡張](https://github.com/sutonomega/sound-canvas/issues/22)を参照してください。

正式Releaseへ転記する際は、相対リンクを公開mainの文書への絶対URLへ置き換え、公開アプリURL・公開SHA・公開確認記録を追記します。
